# Getting Started {#getting-started}

These two pages take you from nothing to a working terminal, in the order you'll
need them. If you only want a parser or an encoder, read the first
page and then go straight to [Building Blocks](libghostty_vt#building-blocks) or
[Input](libghostty_vt#input).

- [Installing](installing.md) - Get the library and link it into your program.
- [Your First Terminal](first-terminal.md) - Create a terminal, write bytes into it, read the
  screen back, and draw it.
